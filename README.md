# Portofolio — Berlyn Tiara Hapsari

> 🌊 Website portofolio pribadi dengan sentuhan estetika *Frank Ocean*, warna biru samudra, dan animasi *Antigravity*.

## Tentang

Situs web portofolio statis untuk **Berlyn Tiara Hapsari**, siswa jurusan **Teknik Jaringan Komputer dan Telekomunikasi (TJKT)** di SMK Negeri 1 Giritontro. Website ini menampilkan profil, keahlian teknis, dokumentasi praktikum, dan informasi kontak.

## Fitur

- **Single Page** dengan navigasi *smooth scroll*
- **Ocean Blue Theme** — warna biru samudra yang *moody* dan *nostalgic*
- **Animasi Antigravity** — elemen melayang dengan CSS animation
- **Tracklist** — keterampilan ditampilkan ala daftar lagu album
- **Discography** — galeri praktikum bergaya *vinyl/album cover*
- **Now Playing Widget** — widget statis lagu Frank Ocean favorit
- **Fully Responsive** — tampil sempurna di HP hingga Desktop

## Teknologi

- HTML5
- CSS3 (tanpa framework)
- JavaScript (Vanilla)
- Google Fonts (Inter)
